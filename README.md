# StudyNook Client Application

StudyNook is a modern web application for reserving quiet study spaces, focus pods, and collaborative lab rooms on-demand.

## Key Features
- **Interactive Room Catalog**: Filter by location floor, price range, and available amenities.
- **Real-Time Booking**: Reserve rooms for custom date and time slots with instant cost estimation.
- **User Dashboard**: Manage active listings, track room reservations, and cancel bookings.
- **Responsive Dark Theme**: Built with Next.js App Router, Tailwind CSS, and custom glassmorphism design tokens.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm / yarn / pnpm

### Installation & Execution
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

## Environment Variables
Create a `.env.local` file in the project root:
```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```
